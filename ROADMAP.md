# m5gfx-flight-ui — Roadmap

Aviation-style (ECAM/Boeing) GUI framework for M5Stack (M5GFX).
Extracted from the m5boat firmware — lives in its `lib/` until stable, then own repo.

## Scope
- DisplayManager (page lifecycle, touch, draw timing)
- IScreenPage / IScreensaver interfaces
- Color system (ECAM/Boeing palettes)
- Drawers: `legacy::` namespace (freeze pixel-perfect visuals) + `v2::` namespace (new)
- AnnunciationBoard, TableDrawers, PageRowDrawer, PageTitleDrawer
- Screensavers (Shapes, Meltable, InProgress)
- Sound FX system (player API)
- Touch / Gesture / Button / Zone / Point
- Fonts: VLW embedded in flash; GFX fonts built-in; optional `fs::FS` loader

## Key decisions
- Keep legacy drawers as-is (screenshot reference), build new alongside.
- Data contract TBD — performance critical, ECAM visuals carefully hand-tuned.
- No knowledge of any app data model; app feeds data in.
- Target: M5Stack Core2/Tough primary, ESP32 + LCD secondary.
- Library never mounts/unmounts a filesystem; app owns `begin()`, lib takes `fs::FS&`.
- Semver. Visual changes to `legacy::` drawers = breaking.

## Resources
- **Fonts:** embedded as `const uint8_t[]` (same approach as Adafruit GFX, U8g2, LVGL).
  Zero RAM, no `uploadfs`, filesystem-agnostic, one TU per font so the linker drops unused sizes.
  Source `.vlw` in `assets/fonts/`, generated by `tools/vlw2h.py`. Generation notes: `docs/FontResources.md`.
- **Sounds:** lib provides player API; small UI clicks may be embedded, large WAVs supplied by app (`fs::FS&` or pointer).
- **Web resources:** not part of this lib.
